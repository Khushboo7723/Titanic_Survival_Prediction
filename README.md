# Titanic Survival Prediction using Machine Learning

Project Overview

This project predicts whether a passenger survived the Titanic disaster using a Decision Tree Classifier. It uses Python and Scikit-learn to perform data preprocessing, model training, prediction, and evaluation.

Dataset

The Titanic dataset contains passenger information such as:

- Passenger class
- Age
- Gender
- Number of siblings and spouses
- Number of parents and children
- Fare
- Port of embarkation

Target Variable: "Survived"

- 0 – Not Survived
- 1 – Survived

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

Project Workflow

1. Data Loading and Exploration
2. Data Cleaning and Missing Value Handling
3. Feature Selection
4. Train-Test Split (80:20)
5. Categorical Feature Encoding
6. Decision Tree Classifier Training
7. Survival Prediction
8. Model Evaluation
9. Confusion Matrix and Decision Tree Visualization

Model Performance

Algorithm: Decision Tree Classifier

Accuracy: 78.77%

Confusion Matrix:

- True Negative: 103
- False Positive: 7
- False Negative: 31
- True Positive: 38

Key Learning Outcomes

- Understanding supervised machine learning
- Preparing data for classification
- Encoding categorical variables
- Training a Decision Tree model
- Evaluating classification performance

Conclusion

The Decision Tree Classifier achieved 78.77% accuracy on the test dataset. This project demonstrates a basic end-to-end machine learning classification workflow.
